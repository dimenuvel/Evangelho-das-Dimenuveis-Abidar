# 🧘 Abidar - The Cosmic Carpet Ride

https://github.com/dimenuvel/Evangelho-das-Dimenuveis-Abidar/releases/tag/v1.0

**Online**: https://abidar-the-cosmic-carpet-ride.ai.studio/

> *"MANTENHA A PRESENÇA — VOCÊ NUNCA FOI A LUGAR NENHUM"*

**Abidar - The Cosmic Carpet Ride** é um jogo arcade estilo retro 16-bits ambientado nas dimensões místicas do cosmos. O jogador controla **"O Cara"** em seu tapete voador intergaláctico, desviando de perigos estelares, coletando itens espirituais, enfrentando chefes cósmicos e buscando a iluminação plena através da serenidade e presença.

---

## 🎮 Introdução ao Jogo

Em um universo repleto de distrações, ilusões temporais e tempestades de poeira estelar, O Cara viaja pelo manto cósmico mantendo a mente serena no presente. Cada fase representa uma dimensão cósmica diferente com desafios únicos, trilhas sonoras sintetizadas e inimigos peculiares.

---

## 🕹️ Mecânicas de Jogo

### Controles
- **Teclado**:
  - `Setas` / `W, A, S, D`: Movimentar o tapete voador (Cima, Baixo, Esquerda, Direita).
  - `Barra de Espaço` / `Z`: Disparar Rajadas de Mantras Psíquicos.
  - `X`: Ativar o **Escudo de Luz Interdimensional** (consome carga de serenidade).
  - `P` / `ESC`: Pausar o jogo.
- **Telas Sensíveis ao Toque (Mobile / Android APK)**:
  - D-Pad / Joystick virtual para movimentação.
  - Botões dedicados para **Disparo** e **Escudo de Luz**.

---

### 🔮 Modos de Jogo

1. **Modo História (Fases Selecionáveis)**:
   - **Fase 1: O Vazio Primordial** — Nebulosas suaves, asteroides leves e introdução aos colecionáveis.
   - **Fase 2: Tempestade de Cristais** — Meteoros velozes, descargas elétricas estelares e maior densidade de inimigos.
   - **Fase 3: Dimensão do Absoluto** — Onde as leis do espaço-tempo se dobram. Inimigos velozes, chefes cósmicos e alto nível de desafio.

2. **Modo Infinito (Endless Cosmic Ride)**:
   - Uma jornada sem fim onde a velocidade e a dificuldade aumentam progressivamente. Teste sua presença mental e dispute o maior recorde no **Ranking Top 10**.

---

### 🌟 Colecionáveis & Power-ups

- 🕉️ **Lótus de Ouro**: Concede pontos de presença e restaura a energia vital.
- 🔮 **Orbe de Energia**: Recarrega a barra de mantra para disparos potentes.
- 🛡️ **Cristal do Escudo**: Garante invulnerabilidade temporária.
- ⚡ **Acelerador Quântico**: Aumenta a velocidade de movimento do tapete voador.

## 🚀 Como Compilar o APK no GitHub Actions

O repositório está equipado com um fluxo de integração contínua (CI/CD) automatizado via **GitHub Actions** (`.github/workflows/build-apk.yml`).

### Passos para gerar o arquivo `.apk`:

1. Faça o **Push** ou envie um **Pull Request** para o repositório no GitHub na branch `main` ou `master`.
2. Vá para a aba **Actions** no seu repositório no GitHub.
3. Selecione o workflow **Build Android APK**.
4. Quando a execução terminar com sucesso, baixe o arquivo de artefato **`Abidar-The-Cosmic-Carpet-Ride-APK`**, que conterá o instalador **`Abidar-The-Cosmic-Carpet-Ride.apk`**.

## 💻 Desenvolvimento Local

### Pré-requisitos
- **Node.js**: Versão 18 ou superior
- **NPM**: Versão 9 ou superior

### Instalação & Execução

```bash
# 1. Instalar as dependências do projeto
npm install

# 2. Iniciar o servidor de desenvolvimento local
npm run dev

# 3. Compilar a versão web para produção
npm run build
```

### Comandos do Capacitor (Android)

```bash
# Sincronizar o build web com o projeto nativo Android
npm run cap:sync

# Compilar o APK debug localmente (requer Java JDK 21 e Android SDK)
npm run build:apk
```
